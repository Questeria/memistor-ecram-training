# Lane ME (X1000 phase 2): the 1960 pencil-lead memistor and electrochemical weights for training

Question, kill lines and every fixed choice: PLAN.md (pre-registered before any sweep). Literature: LITERATURE.md.
State and next steps: STATUS.json. Results are DEV.

## Layout

- `sim/memsim.py` the device model (levels, asymmetry, soft bounds, write noise, spreads, drift, reference), the pulse
  coincidence update, AnalogLinear, Tiki-Taka v2.
- `sim/tasks.py` data (local, sha256-pinned) and models (MNIST MLP, CIFAR CNN, enwik8 byte LM).
- `sim/run.py` one run -> one JSON record. `sim/sweep.py` the pre-registered run lists + a parallel executor.
  `sim/choose.py` the validation-only selections. `sim/devices.py` the device catalog -> records/CATALOG.json.
- `sim/test_memsim.py` 8 checks x 9 planted faults -> records/TESTS.json.
- `records/runs/<task>/*.json` run records; `scratch/` (gitignored) logs and smokes.

## Reproduce (desk)

Python: H:/x1000/bench/venv/Scripts/python.exe (torch 2.7.1+cu126). P2000: `CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1`.

    python -B sim/test_memsim.py --out records/TESTS.json
    python -B sim/sweep.py --phase lrsel --task mnist && python -B sim/choose.py lr mnist
    python -B sim/sweep.py --phase ttsel && python -B sim/choose.py tt
    python -B sim/sweep.py --phase grid --workers 2

run.py sets its own priority to BelowNormal.

## Results (DEV) and where they are

- `VERDICT.md` (generated by `sim/verdict.py final` from `records/RESULTS.json`): the verdict, the catalog map, the minimum
  specs, the CIFAR/LM single-axis points, energy, LM against Adam, the FP sensitivity (D3), the DEV scale check, the kill lines.
- `records/ENERGY.json` (`energy/energy.py`): device-plus-line update energy per catalog device and task, and the
  periphery-inclusive published system figures. `records/SCALE-DEV.json` (`sim/scale.py`): the width check (outside the plan).
- `records/CATALOG.json`: every device spec with the provenance of each field (MEASURED / FIT / CLAIM / ESTIMATE / ASSUMED).
- Pod sittings: `sessions/me-s1..s5-*` (devpod records; the run outputs were copied into `records/runs/`).
- Deviations: `DEVIATIONS.md` D1 (reference bug), D2 (TT lr-matched arms), D3 (second seeds, FP sensitivity).
- Bench proposal: `BENCH.md`, `bench/` (sketch, parts, `analyze_bench.py --selftest`).
