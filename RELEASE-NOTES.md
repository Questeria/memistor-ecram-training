# Release notes: v1.3

The code, records and pulse draws behind the paper "Can memistor-class electrochemical weights train neural networks?" (version 13, October 31, 2026). Cite the concept DOI 10.5281/zenodo.23748861
(all versions). v1.0 (October 28, 2026) held version 9 of the paper, v1.1 (October 29, 2026) version 11, v1.2 (October 29, 2026)
version 12.

v1.3 answers the tenth independent review, a regression review of v1.2 and version 12
(`paper/reviews/REVIEW-10-chatgpt-20261029-full.md`; the response, with each finding verified, is `paper/RESPONSE-TO-REVIEW-10.md`).
The review found the Welch correction of v1.2 right and no new major or critical issue. No experiment was run and no number changed.

- README (finding 1): the "Changes since v1.1" section said that no other printed number changed in v1.2. All eight Welch intervals
  changed (by at most 0.18 in their units), with the count of inconclusive CIFAR arms (2 to 1) and the deviation count (8 to 9); it
  now says so.
- README (finding 2): the layout table counted eight reviews; `paper/reviews/` holds ten (reviews 1 to 10).
- Table 11 (finding 3): its caption, generated by `paper/revision/analyze_rev.py`, said that versions 1 to 11 rounded the Welch degrees
  of freedom down; versions 2 to 11 did (version 1 used another width test). The generator is corrected and the table regenerated
  (`paper/tex/tables/rev_width.tex`; only the caption changes).
- Name check (finding 4): `paper/revision9/name_check_v10.py` left the copied PDF of its self-test open, so removing its temporary
  folder failed on Windows. It now opens every PDF with a context manager and closes it before the file is replaced; it exits 0 with
  NAME_OK on Windows and in WSL (`paper/records/revision12/NAME-CHECK-WINDOWS-F4.json`).
- Paper version 13: the availability section names archive v1.3, the ten reviews and the tenth response, and the history gains
  version 13 (sources in `paper/tex/`, PDFs and HTML in `paper/build/`, 43 pages); version 12 is archived (`paper/tex/v12`,
  `paper/build/v12`), with the scripts and check records of version 13 (`paper/revision12/`, `paper/records/revision12/`).
- 3544 files, 135.4 MB; `SHA256SUMS` covers every file. Pod session records (which hold account identifiers) are not included.
