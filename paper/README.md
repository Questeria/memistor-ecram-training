# Lane ME-PAPER (X1000): the memistor-class electrochemical-weight training study, written up as a paper

Builds on lane ME (`..`, results DEV). Plan, pre-registered and committed before its runs: `PLAN-PAPER.md`; deviations:
`DEVIATIONS-PAPER.md` (when any). State and next step: `STATUS.json`.

## Layout

- `sim/`: the paper simulator.
  - `derive_memsim.py` and `edit_tasks_run.py` derive `memsim.py`, `tasks.py` and `run.py` from lane ME's copies by named anchors.
  - Additions: TTv1, c-TTv2, AGAD, gamma_d2d, fixed alpha, the clean LM validation split, and bookkeeping without device syncs.
  - `test_paper.py` (5 checks, 7 planted faults) writes `records/TESTS-PAPER.json`; lane ME's `test_memsim.py` writes
    `records/TESTS-laneME-checks-on-paper-sim.json`.
  - `sweep_paper.py` holds the pre-registered run lists, the edge-rule lr selection, and the executor.
- `pod/`: `make_payload.py` (sim, lane ME's memsim and TT choice, catalog, choices, MNIST, enwik8 slices) and `run.sh`
  (`ME_PHASES="e2 fplr e1 e3:mnist"` etc.).
- `records/`:
  - `CHOICES-PAPER.json` (validation-only selections);
  - `runs/<phase>/*.json`;
  - `CITE-CHECK.json`;
  - analysis outputs.
- `tex/`: `main.tex`, `refs.bib`, generated `numbers.tex` and `tables/`, figures; `html/` holds the HTML rendering.
