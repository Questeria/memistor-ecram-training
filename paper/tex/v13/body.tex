\section{Code and data availability}\label{sec:availability}
\begin{sloppypar}
One public archive holds everything needed to reproduce this paper, with versions, source hashes, dataset digests and split
offsets, run manifests and licences: Zenodo, \href{https://doi.org/10.5281/zenodo.23748861}{doi:10.5281/zenodo.23748861}
(this DOI cites all versions; version~1.3 of the archive holds version~13 of this paper, version~1.2 holds version~12,
version~1.1 holds version~11, and version~1.0 holds version~9). The same files are on GitHub under
the author's account, \url{https://github.com/Questeria/memistor-ecram-training} (release v1.3). Code is under the MIT License; records, pulse draws, text and
figures are under CC~BY~4.0. The archive keeps the study folder's layout, and the paths below are relative to its
\texttt{paper/} directory. It holds:
\begin{itemize}
\item the plans (\texttt{PLAN-PAPER.md}, \texttt{PLAN-REVISION.md}, \texttt{PLAN-REVISION-2.md},
      \texttt{PLAN-REVISION-3.md}, \texttt{PLAN-REVISION-4.md}), their deviations (\texttt{DEVIATIONS-PAPER.md}), the ten independent reviews
      (\texttt{reviews/}) and the responses to them (\texttt{RESPONSE-TO-REVIEW.md}, \texttt{RESPONSE-TO-REVIEW-2.md},
      \texttt{RESPONSE-TO-REVIEW-3.md}, \texttt{RESPONSE-TO-REVIEW-4.md}, \texttt{RESPONSE-TO-REVIEW-5.md}, \texttt{RESPONSE-TO-REVIEW-6.md}, \texttt{RESPONSE-TO-REVIEW-7.md}, \texttt{RESPONSE-TO-REVIEW-8.md}, \texttt{RESPONSE-TO-REVIEW-9.md}, \texttt{RESPONSE-TO-REVIEW-10.md});
\item the original simulator and the repaired one (\texttt{sim/*\_rev.py}), the explicit pulse streams and probes
      (\texttt{sim/*\_rev2.py}, \texttt{sim/*\_rev3.py}, \texttt{sim/sweep\_rev4.py}), with their checks;
\item the device catalog with per-field provenance;
\item every run record (one JSON file per training run, with its configuration, metric, pulse counts and hardware);
\item the scripts that derive every number, table and figure of this paper from those records (\texttt{analyze.py},
      \texttt{make\_figures.py}, \texttt{energy/energy\_system.py}; for the revision \texttt{revision/analyze\_rev.py},
      \texttt{revision/analyze\_d1.py}, \texttt{revision/compare\_curves.py}, \texttt{energy/energy\_rev.py},
      \texttt{revision2/analyze\_rev2.py}, \texttt{revision3/analyze\_rev3.py}, \texttt{revision4/analyze\_rev4.py});
\item the saved pulse draws of the update probes: \RZDrawN{} NumPy archives (\RZDrawBytes{} bytes, in
      \texttt{draws/rev3/}; each file's SHA-256 is in its probe record and in \texttt{PUBLISHING.md}), from which, with the probe records' metadata (layer, clipping figures,
      bootstrap counts), \texttt{revision4/rebuild\_draw\_tables.py} recomputes every statistic of
      Tables~\ref{tab:rev4_probe_sur}--\ref{tab:rev3_dep} and checks the rebuilt tables against the paper's byte for byte;
\item the citation check (every reference verified against Crossref, the arXiv API or the live URL;
      \texttt{records/CITE-CHECK.json});
\item the bench protocol.
\end{itemize}
In the archive's copies of the reviews and of one response, local file paths are shortened for privacy; the archive's
\texttt{REDACTIONS.md} lists every change. Data: MNIST, CIFAR-10 and enwik8 are public and pinned by digest; they are not
redistributed, and the archive's \texttt{fetch\_data.py} downloads them and checks the digests. All text data used for training
is human-written (Wikipedia, 2006).

\end{sloppypar}
